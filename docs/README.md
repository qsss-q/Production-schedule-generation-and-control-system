## Стек

**Java 21 LTS + Spring Boot 3.4**, PostgreSQL 16, Flyway, Quartz, WebSocket/STOMP.

Методичка рекомендует C#/.NET, команда взяла Java — обоснование и порядок
согласования в [07-технический-стек.md](07-технический-стек.md). Предметная часть
документов от стека не зависит: при смене языка меняются разделы 02 и 03,
остальные остаются как есть.

## Открытые вопросы к куратору

1. **Стек.** Согласовать Java вместо рекомендованного C#/.NET (текст вопроса — в 07).
2. **Трактовка серийности.** Вторая цифра в «9-2» — шаг нумерации печей внутри
   серии или интервал между выдачами? Влияет на порядок выдачи в планировщике.
3. Реальные номера батарей и печей в ЕКС — использовать вымышленные или подставить
   фактические из отчёта 2011 г.?
4. Нужна ли ролевая модель (оператор / мастер / инженер) уже в MVP? По методичке
   безопасность — отдельный кейс, но журнал действий уже требуется.
5. План по поступающему коксу / объёму выпуска — куратор обозначил как «за пределами
   MVP». Подтверждаем?

## Источники данных

Основной источник предметных данных — **отчёт по производственной практике 2011 г.**
(«Евраз Кокс-Сибирь», СибГИУ), разбор коксового цеха ЕКС. Технологические нормативы
уточнены по «Справочнику коксохимика», профильным материалам ЦХУиПКХП и профильным
материалам НГТУ. Полные перекрёстные ссылки — в [06-справочник-нормативов.md](06-справочник-нормативов.md).
