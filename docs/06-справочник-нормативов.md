## 3. Временны́е нормативы

### Циклы

| Параметр | Значение | Источник |
|---|---|---|
| Период коксования | 13–18 ч | [ВИКИ], [НГП] |
| Типовой рабочий период | 14–15 ч | [СПР-КХ] |
| Ремонтная часть цикла при обороте 14–15 ч | 1,0–1,5 ч | [СПР-КХ] |
| Цикличная остановка, минимум | 2 ч | [ЦХУ] |

| Выдержка кокса на рампе | 15–20 мин | [ЦХУ] |

### Операции

| Параметр | Значение | Источник |
|---|---|---|
| Отклонение периода коксования от заданного | ≤ **5 мин** | [СПР-КХ] |
| Отклонение фактической выдачи от графика | ≤ 5 мин (динасовые), ≤ 10 мин (шамотные) | [СПР-КХ] |
| Выдача → загрузка камеры | ≤ **8 мин** | [ЦХУ] |
| То же, работа с одной пустой камерой | ≤ **18 мин** | [ЦХУ] |
| То же, работа через две пустые камеры | ≤ **20 мин** (по разрешению гл. инженера) | [ЦХУ] |
| Разрыв между оборотом и периодом коксования при одной пустой камере | 12–15 мин | [СПР-КХ] |
| Печь с открытой дверью | ≤ **5 мин** | [ЦХУ] |
| От снятия дверей до установки | ≤ **10 мин** | [ЦХУ] |
| Отключение от газосборника до выдачи | не ранее чем за **20 мин** | [ЦХУ] |
| Отключение стояка (при обороте ≥ 20 ч) | за **2–3 ч** до выдачи | [ЦХУ] |
| Пароинжекция при загрузке | ≤ **6 мин** | [ЦХУ] |
| Задержка загрузочного вагона над открытыми люками | ≤ **5 мин** | [ЦХУ] |
| Одновременно открытых крышек стояков | ≤ **3** печи | [ЦХУ] |
| Форсирование выдачи после простоя | ≤ **1–2 печи/час** сверх нормы | [СПР-КХ] |
| Разбор загрузочного вагона: тупик электровоза перед ДСМ | 1–1,5 м впереди | [ЦХУ] |

## 8. Что стоит перепроверить у заказчика

| Вопрос | Почему важно |
|---|---|
| Точная трактовка второй цифры серийности | Влияет на порядок выдачи на каждой печи |
| Актуальная рабочая схема для ЕКС | 2011 vs 2026 могут отличаться после реконструкции |
| Фактическое число печей по каждой батарее сегодня | Определяет правдоподобность демо |
| Реальные частоты отказов оборудования | Сейчас подобраны на глаз, хороши для демо, но не для отчёта |
| Нужна ли ветка «работа с пустой камерой» в UI | Требует отдельного сценария и своих ограничений |
