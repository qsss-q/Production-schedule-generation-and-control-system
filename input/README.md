# Исходные материалы заказчика

Документы, полученные от ООО «ЕвразТехника ИС» и НГТУ. **Не редактируются** —
при необходимости уточнения задаются вопросы куратору (Игорь Дыминский).

| Файл | Описание |
|---|---|
| `ТЗ_ЕвразТехника_ИС_перечень_кейсов.docx` | Перечень трёх проектных кейсов. Утверждён проректором 01.09.2026, подписан А. А. Якименко. **Кейс 1** — наш: «Система формирования и контроля производственного графика» |
| `Отчёт_производственная_практика_2011_ЕКС.doc` | Отчёт по производственной практике, СибГИУ, 2011 г., предприятие «Евраз Кокс-Сибирь». 56 страниц. Использован как основной источник предметной области |
