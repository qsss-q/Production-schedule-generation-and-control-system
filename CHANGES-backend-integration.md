# Что изменилось во фронте при подключении бэкенда

Дизайн и вёрстка не менялись: правки только в данных (вместо констант запросы к бэкенду). Бэкенд запускается
отдельно (`docker compose up --build` в репозитории бэкенда), фронт как обычно: `npm run dev`.

## Новые файлы

| Файл | Что внутри |
|---|---|
| `src/api/client.js` | все запросы к серверу (две группы: симулятор `/api/v1` и БД `/api`) |
| `src/api/useLive.js` | опрос симулятора раз в секунду: состояние, печи, машины, лента, события |
| `src/utils/format.js` | время (по Новосибирску, смена с 08:00), дата |
| `src/utils/ovenView.js` | состояние печи с бэкенда -> цвет, подпись, класс (вместо `getOvenData`) |
| `src/utils/eventView.js` | событие симулятора -> категория, заголовок, цвет точки в журнале |

## Изменённые файлы

- `vite.config.js`: прокси `/api` -> `localhost:8080` (адрес бэкенда в коде не нужен, CORS не мешает).
- `App.jsx`: данные из `useLive`; ПУСК / ПАУЗА / СТОП вызывают бэкенд (СТОП = сброс на начало смены);
  время в шапке, счётчик отклонений на колокольчике, красная полоса, если бэкенд недоступен.
- `MainWorkspace.jsx`: печи, машины и лента берутся из бэкенда; печей **69** (два ряда 35 + 34), а не 60;
  легенда считается по состояниям печей; «Авто: самые проблемные» выбирает аварии и самые долгие передержки;
  график температуры берётся из БД (если замеров нет, остаётся прежний запасной график).
- `LeftPanel.jsx`: настройки и справочник оборудования из БД; переключатели доступности работают;
  «Сформировать график» сохраняет настройки и график в БД. Поля «Окно смены» и «Макс. простой» разбираются
  из текста, формат нужно сохранять.
- `RightSidebar.jsx`: отклонения и журнал событий из симулятора с фильтрами (оборудование, период, теги);
  «Действия оператора» из БД.
- `Modals.jsx`: окно «Симулятор» отправляет параметры на бэкенд (ускорение, частота, вероятность, seed,
  «Сгенерировать отказ», «Сбросить»). Модалка сравнения алгоритмов не менялась (данных на бэкенде пока нет).

## Что стоит знать

- Цвета печей по контракту Вани: готова зелёный, коксование жёлтый, передержка оранжевый, авария красный,
  выдача/загрузка синий. Поэтому **легенда над батареей изменилась**: теперь по состояниям, а не «в работе /
  отставание / срыв / авария».
- Не подключено (на бэкенде нет): сравнение алгоритмов, «Загрузить данные», «Справочник», «+ Новый».
- Заголовок «Лента освещает события», скорее всего, опечатка («ближайших»). Я не трогала.
